# Mesto

Интерактивная страница для публикации карточек с фотографиями. Проект подключен к API Mesto: данные пользователя и карточек загружаются с сервера, профиль и аватар редактируются, карточки добавляются, удаляются и лайкаются.

## Команды

```bash
npm install
npm run dev
npm run build
npm run deploy
```
